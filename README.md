# Agent Project

This repository contains the codebase for the Agent project, separated into a frontend and a backend.

## Project Structure

- **[`agent-frontend`](./agent-frontend)**: The user interface built with React, TypeScript, and Vite.
- **[`agent-backend`](./agent-backend)**: The API backend built with Hono and Cloudflare Workers.

## Getting Started

To run the project locally, you will need to start both the frontend and backend development servers.

### Frontend

Navigate to the `agent-frontend` directory, install dependencies, and start the development server:

```bash
cd agent-frontend
npm install
npm run dev
```

### Backend

Navigate to the `agent-backend` directory, install dependencies, and start the development server:

```bash
cd agent-backend
npm install
npm run dev
```
